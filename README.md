# NIA Chat Bot

First test version of the NIA chatbot.

## What this version does

- Opens as a mobile-friendly chat page.
- Lets you send messages.
- NIA responds with basic test replies.
- No API key is required for this first test.

## Test

Open `index.html` in a browser and try:

- `Hello`
- `Who are you?`
- `Test`
- `Help`

## Next stage

Once the interface is working, the demo replies can be replaced with a secure AI backend. Never put a private API key directly into `app.js` or other browser code.
